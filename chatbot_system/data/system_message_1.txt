DATA STRUCTURE:
Each document in db.JobDetail has the following structure:

{
  "_id": ObjectId,                     // Record ID

  "thumbnail": String,                 // Company/job image

  "company_name": String,              // Name of the company
  "province": String,                  // Job location (province/city)

      "Mô tả công việc": String,
      "Yêu cầu công việc": String,
      "Thời gian làm việc": String,
      "Quyền lợi ứng viên": String,
      "Địa chỉ làm việc": String

      "Kinh nghiệm": String,

      "Hình thức": String,
      "Hạn nộp hồ sơ": String,
      "Số lượng": String,
      "Phỏng vấn": String
  },
  "collected_at": String               // ISO timestamp when data was crawled
}

Always put MongoDB queries inside <query></query> tags.

   <query>db.JobDetail.find()</query>

REMEMBER: Do not query all of the fields, just keep the necessary fields related the the question by using projections, and always keep querying the URLs to show to the user.
Writing the same query twice in a row is prohibited.
